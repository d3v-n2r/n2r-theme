# n2r-theme

The theme for [n2r-engine](https://github.com/d3v-n2r/n2r-engine): minijinja templates + SCSS + vanilla JS, targeting full feature parity with the [Chirpy](https://github.com/cotes2020/jekyll-theme-chirpy) Jekyll theme — with personal color/font/structure tweaks and new **portfolio** and **gallery** sections.

Credit: design and feature surface ported from Chirpy (MIT, © cotes2020). This is a port to a new engine, not a fork.

Status: pre-alpha — the engine it targets is still in private development.
