{# Icons. A theme with none of these is not merely plain: browsers request `/favicon.ico` on every page load whether it is declared or not, so every navigation costs a 404, and an iOS bookmark falls back to a screenshot of the page. The SVG is listed first and is what any current browser uses; the PNG and the ICO are there for everything that does not read SVG icons, which still includes most feed readers and chat clients. A site replaces any of these by putting a file at the same path under its own `assets/` — the engine copies the theme's tree first and the site's over it. #}
